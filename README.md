# Weather App

A simple command-line Weather Application built in Python using the **OpenWeatherMap API**.

## Features

- Get live weather of any city
- Shows:
  - Temperature (°C)
  - Weather condition
  - Humidity
  - Wind speed
- Clean and beginner-friendly code

## How to Run

1. Install the required library:

```bash
pip install requests
```

2. Open `weather.py` and replace `YOUR_API_KEY` with your actual OpenWeatherMap API key.

3. Run the program:

```bash
python weather.py
```

## Example

```
Enter city name: London

Weather in London:
Temperature : 18°C
Condition   : Clear sky
Humidity    : 64%
Wind Speed  : 3.5 m/s
```
